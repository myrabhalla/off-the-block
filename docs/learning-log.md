# Myra's Learning Log

What I've learned building Off The Block, in my own words. Newest at the top.

## 25 Nov 2026: Agents and a Chief of Staff
**In my words:** I talk to one Chief of Staff. It hires specialist helpers (a builder, a checker, a safety
editor, a privacy guard, a release manager) and checks their work before showing me.
**Analogy:** like a head chef running a kitchen of specialist cooks.
**Where it shows up:** `CLAUDE.md`, `.claude/agents/`

## 25 Nov 2026: Git, commit and push
**In my words:** Git is a time machine for the project. A commit is a photo of the work with a caption.
A push sends the photos to GitHub, a safe in the cloud. Now it happens automatically.
**Analogy:** photo album and a safe.
**Where it shows up:** every save; the "saved" message.

## 25 Nov 2026: API vs MCP
**In my words:** an API is how my *app* talks to other services by itself (like Firebase). MCP is how
*Claude* gets keys to use apps for me (like Canva).
**Where it shows up:** Firebase (API) later; Canva for the book (MCP).

## 21 Oct 2026: Website → app
**In my words:** the website is the painting, Capacitor is the picture frame that turns it into an app,
and Xcode is Apple's workshop where the framed app gets built.
**Where it shows up:** `ios/`, `capacitor.config.json`

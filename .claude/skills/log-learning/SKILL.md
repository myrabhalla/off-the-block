# Log a learning

Add an entry at the top of `docs/learning-log.md`:

```
## <date> — <topic in a few words>
**In my words:** <one or two sentences, simple, the way Myra would say it>
**Analogy:** <the ELI5 picture we used, if any>
**Where it shows up in our project:** <file or workflow>
```

Log every new concept you teach her (for example GitHub, versions, an analytics event), not only ones she asks for.
Save to GitHub. No need to announce it beyond "added to your learning diary".
